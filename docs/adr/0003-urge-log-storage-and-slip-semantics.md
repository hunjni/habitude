# 冲动日志存 `Habitude/Urge/YYYY-MM-DD.md`；失守只从冲动日志推导

坏习惯的冲动日志存于 `Habitude/Urge/YYYY-MM-DD.md`（每日一文件，与 Log/ 平行），条目格式 `- HH:MM | 情境 | 强度1-10 | 应对 | 结果`。不塞进打卡 Log 文件（会污染 `- [x]` 解析），不用单文件追加（易冲突、难手编）。

失守（slip）的事实来源**只有冲动日志**（结果 = 屈服）：详情视图提供「记录一次失守」按钮，本质是预填一条屈服条目。「距上次失守天数」「没打勾 ≠ 失守」——不做被动推导，因为「今天没打勾」和「今天没记录」无法区分。坏习惯打勾语义复用现有 `- [x]` 行（仅 UI 语义/图标翻转），统计与缓存层零迁移。

## 修订（2026-09-22，阶段五实现时）

条目格式定为 6 字段：`- HH:MM | <habitId> | 情境 | 强度1-10 | 应对 | resisted|slip`。相对初稿多出 `habitId` 一列——多个坏习惯并存时，无归属字段的条目无法支撑按习惯的「距上次失守天数」与冲动模式分析。结果值用固定 token（`resisted`/`slip`）而非本地化词，保证解析与 UI 语言无关。
